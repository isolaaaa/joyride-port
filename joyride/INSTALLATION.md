# Instalação / Installation — Jetpack Joyride

## Português

1. Extraia o conteúdo deste arquivo para a pasta `ports/` do seu cartão de memória (usada pelo PortMaster).
   A estrutura resultante no cartão deve ser:
   - `ports/Joyride.sh`
   - `ports/joyride/`

2. Copie o arquivo APK oficial do seu jogo **Jetpack Joyride v1.16.2** para a pasta:
   - `ports/joyride/gamedata/` (ou diretamente em `ports/joyride/`)
   Nome do arquivo padrão: `com.halfbrick.jetpackjoyride.apk`.

3. Inicie **Jetpack Joyride** no menu Ports do seu console (R36s / ArkOS / AmberELEC / Rocknix).
   Na primeira execução, o extrator automatizado validará o APK e extrairá os arquivos necessários.

1. Extract the contents of this archive into the `ports/` directory of your SD card (used by PortMaster).
   The resulting layout must contain:
   - `ports/Joyride.sh`

   On the first launch, the automated extractor will validate and prepare the game data.
